# Ducky v1 — Open Source
This is the source code of Ducky v1, up until v1.7.0 Stable. If you don't know what you're doing, it probably isn't a good idea to try to get this running, but do what you wish. A secrets template is available in example.secrets.lua. You're on your own from there.

## Why are there no old commits?
This repository is freshly created, as we prefer to keep the commit history private in order to protect sensitive data and external API tokens that were removed prior to going open-source.

## Can I propose changes?
We will only accept bug fixes via pull requests, nothing else. If you wish to make other changes, just fork the repository.
